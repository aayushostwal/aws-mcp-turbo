# aws-mcp-turbo v0.1.1

Automated release publishing; no changes to AWS action behavior.

- Stable version tags now run validation, publish attested GitHub binaries, then publish
  `@ostwal/aws-mcp-turbo` through npm trusted publishing (OIDC), without an npm token.
- Tag/package version and release-note checks, main-branch ancestry, serialized releases,
  immutable npm-version checks, and a guard against moving npm's `latest` backwards.
- Fresh-cache installation and MCP smoke checks before and after npm publication.
- Bounded registry propagation retries and documented recovery for partial releases.

```sh
npx -y @ostwal/aws-mcp-turbo@0.1.1 --version
```

Requires Node.js 22+, macOS/Linux arm64 or x64, and local AWS credentials for AWS queries.
Mutations remain disabled by default. Live AWS/SSO and GUI-client acceptance remains unverified;
the initial release's [benchmark limitations](https://github.com/aayushostwal/aws-mcp-turbo/blob/v0.1.1/docs/benchmarks.md)
still apply. Windows and macOS notarization are not provided.

To recover from a regression, pin `@ostwal/aws-mcp-turbo@0.1.0` in your MCP client and restart
it, or disable the server entry. This does not undo AWS writes. Never replace a published
version or move its tag; issue a separately versioned patch instead.
