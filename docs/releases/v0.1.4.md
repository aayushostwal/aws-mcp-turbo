# aws-mcp-turbo v0.1.4

- `aws_discover` now includes structured content as well as its existing text response for MCP client compatibility.
- `aws_query.regions` can fan out the same read action across up to eight regions, with four concurrent requests and labeled partial results.
- Per-query region support from v0.1.3 remains available; the server default is unchanged when `region` is omitted.
