# aws-mcp-turbo v0.1.2

This release makes the 30-service read expansion available through npm/npx. It supersedes
v0.1.1, whose GitHub binaries were published but whose npm job failed before publication.

- Removed the token-auth npm configuration generated by `actions/setup-node` so the release
  job can use GitHub Actions OIDC trusted publishing.
- Added a workflow regression check for that configuration.
- Updated installation and MCP examples to use the npm `latest` dist-tag.

```sh
npx -y @ostwal/aws-mcp-turbo@latest --version
```

Requires Node.js 22+, macOS/Linux arm64 or x64, and local AWS credentials for AWS queries.
Mutations remain disabled by default. Live AWS/SSO and GUI-client acceptance remain unverified.
