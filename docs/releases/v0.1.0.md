# aws-mcp-turbo v0.1.0

Initial public release of the local, native AWS MCP server.

## Install

Requires Node.js 22+ and macOS or Linux on arm64/x64. No repository clone or Go compiler is needed.

```sh
npx -y @ostwal/aws-mcp-turbo@0.1.0 --version
```

For MCP client configuration, see [the client guide](https://github.com/aayushostwal/aws-mcp-turbo/blob/v0.1.0/docs/clients.md).
AWS calls use your existing local credentials; SSO login is performed separately with the AWS CLI.
The launcher downloads the matching native binary, verifies its SHA-256 checksum, and caches it.

## Included

- Four tools: discovery, projected read queries, diagnostic macros, and guarded mutations.
- Twelve read actions across EC2, S3, Lambda, ECS, and CloudWatch Logs.
- JMESPath projections, recursive pruning, Markdown/TSV/compact JSON, and session-local log cursors.
- ECS stopped-task and Lambda timeout diagnostic macros.
- Mutations disabled by default; opt-in execution requires an audit log and approval hook.
- Go 1.27.1 builds for macOS/Linux arm64/amd64, checksums, and GitHub build attestations.

## Validation and limits

Offline Go tests, race tests, npm launcher tests, packaged npm execution, stdio protocol smoke tests,
and vulnerability scanning are release gates. Generic MCP protocol integration is tested; no
Claude Desktop or Cursor GUI version is certified by this release. Live AWS/SSO acceptance is
not yet completed. Use a least-privilege sandbox role for your initial evaluation.

Synthetic measurements on Apple M4/macOS arm64: four tool definitions occupy 258/271 tokens,
and the 1,000-row projection pipeline takes approximately 0.57 ms. Mean response token savings
are about 71%, not the aspirational 85%. These are not AWS network latency measurements;
the claimed 3–5× remote-proxy speedup has not been verified. See [benchmark details](https://github.com/aayushostwal/aws-mcp-turbo/blob/v0.1.0/docs/benchmarks.md).

Windows, macOS notarization, and stable Homebrew installation are not validated in this release.
The npm wrapper checks SHA-256; it does not itself verify GitHub attestations.

## Disable or recover

If startup, integrity checks, or tool behavior fail, disable/remove this server entry in the MCP
client and stop its process. The client owns its lifecycle; no daemon or listener is installed.
Clean shutdown on stdin closure is covered by the stdio smoke test. As the first release there
is no previous public version to pin. Report the failure and wait for a separately versioned fix;
do not bypass checksum failures. Disabling the server cannot undo any explicitly approved AWS writes.

Maintainers should deprecate a defective npm version with a clear advisory rather than replacing
its published contents or moving its Git tag. Public versions and release assets are immutable.
