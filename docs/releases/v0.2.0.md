# aws-mcp-turbo v0.2.0

- 76 AWS services and about 2,700 read operations, up from 30 services and 61 operations. Actions now come
  from the AWS SDK clients; adding a service is one line.
- Three tools. `aws_diagnose` is folded into `aws_query` as `macro`.
- `aws_query` adds `fields`, `group`, `all` (page to the end), `queries` (up to eight parallel reads)
  and nine recipes.
- Compact tab-separated output by default, with shared values and prefixes stated once. Oversized
  results are cut to the rows that fit instead of failing.
- Any SDK write can be previewed or approved through `aws_mutate`; operations that return credentials or
  key material are not callable.
- Release binaries are about 190 MB because of the bundled services. Each release also ships a gzip copy
  (about 40 MB) which the npm launcher downloads.

Single-record fixtures average 78% fewer tokens (71% before) and listings of 25 to 40 records 90% to 97%.
No comparison with the official AWS MCP Server has been run; see `docs/benchmarks.md`. AWS calls were
tested against stubbed HTTP responses, not a live account.
